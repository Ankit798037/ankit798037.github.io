# Ankit Tiwari — GitHub Pages Portfolio

1. Create a **public** GitHub repository named `YOUR-USERNAME.github.io`.
2. Upload `index.html` and the `work` folder.
3. Go to **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select `main` and `/ (root)` → **Save**.
6. Your portfolio will be available at `https://YOUR-USERNAME.github.io`.

Replace the sample files in `work/` with your actual work and update the links in `index.html`.

Only publish work you are permitted to share publicly. Remove confidential client/student/employer information.
